# Sudarshan Chakra 🌀

An interactive, gesture-controlled visual experience inspired by the divine Sudarshan Chakra. This project uses real-time hand tracking to summon, control, and launch a dynamically rendered chakra with cinematic effects directly in the browser.

---

## ✨ Features

* **Real-time Hand Tracking** using MediaPipe
* **Gesture-Based Interaction**

  * Show hand → Summon chakra
  * Hold → Stabilize and rotate
  * Flick → Launch
* **Procedural Chakra Rendering**

  * Multi-layered concentric rings
  * Dynamic lighting and gradients
  * Perspective tilt for depth
* **Advanced Visual Effects**

  * Lightning summoning effect
  * Glow compositing
  * Motion trail during launch
* **Immersive UI**

  * Cinematic overlay (vignette + tint)
  * Dynamic status HUD
  * Smooth state transitions

---

##  Tech Stack

* HTML5 Canvas
* JavaScript (Vanilla)
* MediaPipe Hands
* Camera Utilities

---

##  How It Works

1. Allow camera access
2. Show your hand to the camera
3. The chakra will summon with lightning
4. Hold steady to stabilize
5. Flick your hand to launch it

---

##  Highlights

* Custom rendering engine built using Canvas
* State machine-driven interaction system
* Gesture recognition using motion buffering
* Layered glow rendering with additive blending
